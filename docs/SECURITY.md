# Watchtower Crypto — Security and Evidence Integrity

Version 0.1 is a **manual research journal**, not a crypto trading, signal selling, wallet access or market surveillance service.

- Local data is stored under `watchtower.crypto.research.v1` in browser localStorage. It is not encrypted, multi-device synced, identity verified or backed up.
- Source links must use HTTPS, have no embedded URL username/password, and are opened with `rel="noopener noreferrer"`. HTTPS alone does not make a source reliable.
- Manually entered observations and KOL notes remain unverified. The program never invents popularity, holdings, KOL endorsements, trades, trends or investment performance.
- Public source data and text are HTML-escaped when rendered. Form fields are length limited; storage is validated before use.
- JSON opportunity export removes local-only fields and retains the exact V1 interchange format. The export is editable and is not a private-key signature or cryptographic attestation.
- There are no API keys, wallet connectors, transaction execution, custody operations, token launch features or hidden promotional arrangements.
- The BodyBagz hub cannot access this app's local browser storage; any future integration should use explicit consent and properly authenticated backend contracts when personal data is involved.

Any future real-time market feeds require licensed or permitted sources, provenance and timestamps, published risk/quality methodology, and security review. Do not infer that a KOL mention recommends a token or guarantees future returns.
